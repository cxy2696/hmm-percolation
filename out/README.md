# Reference outputs

These files are generated by `scripts/reproduce.sh` with fixed seeds. They are
kept in the repository so that tests can compare against a known model and so
that the Markdown report has a concrete example.

They are not performance claims. For the current numbers and their
limitations, see `docs/results.md`.

- `regime/` — 3-state main run (`states.csv`, `equity.csv`, `metrics.json`,
  `report.md`, model files).
- `regime_s2/`, `regime_s0/`, `regime_noperc/`, `regime_w30/` — variants used
  for the comparison tables.
- `connectedness/` — rolling correlation percolation.
- `perc_*` — lattice scans, finite-size fits, mean-field table.

To rebuild:

```bash
./scripts/reproduce.sh
```
