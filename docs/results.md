# 结果与检查

这里放可以核对的数字。命令见 [reproduction.md](reproduction.md)。所有结果来自固定种子的合成数据，不是真实市场业绩。

## 1. 渗流

### 1.1 二维键渗流（方格，开边界）

| L | 交叉点 |
| --- | --- |
| 32 | 0.4872 |
| 64 | 0.4916 |
| 128 | 0.4951 |
| 256 | 0.4973 |
| 外推 $p_c(\infty)$ | **0.4997** |

已知精确值 0.5。以 $\nu=4/3$ 拟合 $p_c(L)=p_c+a L^{-1/\nu}$，R²=0.9936。200 次重复，二分 16 次。

这是数值验证，不是 $p_c=1/2$ 的证明；证明见 [Kesten](https://doi.org/10.1007/BF01197577)，数学笔记里明确标为引用。

### 1.2 二维点渗流

| L | 交叉点 |
| --- | --- |
| 32 | 0.5701 |
| 64 | 0.5828 |
| 128 | 0.5859 |
| 256 | 0.5892 |
| 外推 | **0.5948** |

已知 0.592746，误差 0.0021，R²=0.9705。误差比键渗流大，符合有限尺寸修正更强的预期。

### 1.3 平均场

| 检查 | 结果 |
| --- | --- |
| ER $S(c=2)$ | 0.796812 |
| Poisson 配置模型 $T=1$ 与 ER 理论 | 差小于 1e-6 |
| $R_0=1.2$ | $S\gt 0$ |
| $R_0=0.8$ | $S=0$ |
| 二度正则图 $T=1$ | $R_0=1,\ S=0$（树近似在临界点的约定） |
| 三度正则图 $T=1$ | $R_0=2,\ S=1$ |

二度、三度两行是配置模型求解器的边界测试。另一个测试用一半一度、一半三度（ $T=1$）：旧式给 $S=1$，先解邻居灭绝概率的新式给 $q=1/3$、 $S=22/27\approx0.8148$。详细推导见数学笔记 2.3。

### 3.3 策略对照

同一段样本外、同一 5 bps 成本、同一执行滞后。`hmm` 与 `hmm_gate` 使用默认三状态模型；其余是不依赖 HMM 的基线。

| 策略 | 总收益 | CAGR | 年化波动 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: | ---: | ---: |
| buy_hold | 92.77% | 14.90% | 18.34% | 0.85 | -33.83% |
| constant 0.5 | 41.62% | 7.64% | 9.17% | 0.85 | -18.27% |
| vol_target | 56.89% | 10.00% | 11.51% | 0.89 | -17.96% |
| momentum 60d | 37.01% | 6.89% | 14.34% | 0.54 | -24.60% |
| gate_only | 102.59% | 16.11% | 16.92% | 0.97 | -25.64% |
| hmm | 53.40% | 9.48% | 12.81% | 0.77 | -22.40% |
| hmm_gate | 60.65% | 10.55% | 12.19% | 0.88 | -16.90% |
| hmm_vol | 33.35% | 6.28% | 7.94% | 0.81 | -12.89% |
| hmm_vol_gate | 36.27% | 6.77% | 7.66% | 0.89 | -9.81% |

`vol_target` 的 Sharpe 略高于 HMM+闸门，说明其中一部分“改善”只是降波动；`momentum` 在这份数据上没有择时价值。单独 `gate_only` 的 Sharpe 最高（0.97），说明这份合成数据上主要是相关结构闸门在起作用，HMM 没有额外贡献。`hmm_vol_gate` 回撤最低，但绝对收益也最低。完整讨论和规则定义见 [strategies.md](strategies.md)。

## 6. 结果不能说明什么

- 合成市场是单因子、状态数已知、无缺失、无停牌；真实相关矩阵更脏。
- 5 bps 只是换手成本，没有冲击、借券、涨跌停、容量。
- 单一实现路径，没有 bootstrap、多市场、参数扰动；不能据此说“策略显著”。
- 渗流闸门降低回撤的代价是牺牲上涨参与度；绝对收益仍低于买入持有。
- 配置模型函数是树近似， $T=1$ 的二度链会高估 $S$；有限图结论要靠模拟。
